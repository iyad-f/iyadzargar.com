# iyadzargar.com

My personal website [iyadzargar.com](https://iyadzargar.com).

## Development

Prerequisites:

- Go 1.26+
- [pre-commit](https://pre-commit.com)
- [golangci-lint](https://golangci-lint.run) v2
- [Tailwind CSS standalone CLI](https://tailwindcss.com/blog/standalone-cli)

```sh
make setup   # install git hooks and download dependencies
make dev     # run with live reload at http://localhost:8080
```
